# 字段规范与 Excel 结构

## 统一字段（每件商品一条记录）

| 字段 | 含义 | 抽取方式 |
| --- | --- | --- |
| name | 清洗掉促销口水词后的品名 | 规则：TITLE_NOISE 词典清洗；AI 可辅助 |
| brand | 品牌 | 品牌词典最长匹配 + 店铺名推断，可手改 |
| keywords | 话题标签 + 标题/功效词，供 SEO/选词参考 | 规则，最多 12 个，顿号分隔 |
| effects | 保湿/美白/抗皱等 | 功效词典匹配，最多 10 个 |
| selling_points | 标题【】内容 + 含成分/功效/数据的句子 | 规则评分筛选，最多 12 条，分号分隔 |
| ingredients | 成分列表 | 成分词典匹配（长词优先），最多 20 个 |
| ingredient_diff | 对比组内配方特色/成分差异 | 单品抽取留空；形成对比组并人工核对后再填 |
| price | 价格（数字） | ￥/元/到手价/券后价 正则提取 |
| sales | 销量（数字，万已换算） | 已售/月销/销量/付款 正则提取 |
| sales_text | 销量原文（如“已售8.2万件”） | 保留可追溯 |
| shop | 店铺或作者 | 采集字段/手填 |
| url | 商品/笔记链接 | 采集字段/手填 |
| keyword_group | 搜索词/分组 | 任务参数 |

`raw_text`、`record_id`、`extraction_method`、`review_status` 等证据与质量字段保留在 JSON / `research_bundle.json` 中；当前 Excel 固定 18 列不展示这些字段。

## Excel Sheet1：竞品数据明细

固定 18 列表头：

序号、平台、商品名称、品牌、关键词、功效、核心卖点、成分、成分差异、价格(元)、销量、销量原文、店铺/作者、商品链接、搜索词/分组、数据来源、抓取时间、备注

格式约定：表头加色加粗、首行冻结、自动筛选；价格/销量用数字格式；商品链接可点击；功效/卖点/成分列自动换行。

## Excel Sheet2：横向对比

按 `keyword_group` 分组，每组：第一行对比组标题，第二行一个商品一列，之后每行一个对比维度（平台/品牌/价格/销量/功效/核心卖点/成分/成分差异/商品链接/备注）。

## Excel Sheet3：词频统计

- 高频功效 TOP10、高频成分 TOP10、高频关键词 TOP10（按顿号/逗号/分号/竖线分隔计数）
- 汇总信息：商品总数、涉及平台、导出时间、搜索词

## 抽取逻辑要点

- 关键词 = 话题标签（#）+ 标题清洗后词元 + 标题/正文前 200 字内的功效词。
- 卖点评分：含卖点标记（卖点/主打/专为/配方/专利…）+2，含功效/成分 +1，含数字量化（28天/7天/倍率/%）+1，含价格销量词 -2，≥2 分入卖点。
- 成分排序：命中的成分按长度降序（长词优先，如「神经酰胺NP」优先于「神经酰胺」）。
- 品牌：品牌词典中命中且最长者优先；否则取店铺名首段（旗舰店/官方店等后缀之前）。
- 不要改列结构：新信息写备注列，或扩展脚本后统一升级。
